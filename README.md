# 栖刻 QIKE · 司机座舱

面向网约车司机的智能座舱交互原型，涵盖候单选点、驻点用餐、短休、暂时离车、恢复接单与订单服务流程。

## 在线体验

[打开交互原型](https://ocelot-uxui.github.io/qike-driver-cockpit/)

建议使用电脑或平板横屏体验。界面采用 1440×810 逻辑画布，并保持 16:9 比例自动缩放。

## 推荐体验路径

1. 从车辆首页进入候单地图，筛选停车与补给地点。
2. 查看地点详情，前往并模拟到达。
3. 选择用餐、短休或离车，设置时长与接单状态。
4. 结束休整后确认驾驶准备，再主动恢复候单。
5. 点击屏幕外的“模拟来单”，体验接驾、上车与送达流程。

顶部可切换早间、午间和晚间场景。车辆热点、车控、温度、风量、照明、搜索、收藏与地图缩放可以操作。

## 文件与部署

- `index.html` 是完整单文件版本，样式、脚本与图像均已内嵌，无需安装依赖。
- 直接用浏览器打开也可体验，刷新后演示状态重置。
- GitHub Pages 从 `main` 分支根目录发布。

## 说明

所有道路、地点、停车与设施信息、订单、收入、派单及车辆控制均为模拟数据。原型未连接真实网约车平台或车辆，不用于实际导航或驾驶。

车辆与座椅为 AI 辅助生成的视觉素材，界面布局及交互由 HTML、CSS 和 JavaScript 实现。
